Q5. [MP Section A]
Doubt: for lexer part ,input like hello|hi wld output like word(hello)op_pipe word(hi) so we wld break at all ops and whitespaces for words what abt hello"hi"hiii is this 3 words like word(hello)word(hi)word(hiii) or is it word(hellohihiii) same doubt for single quote also
Answer: [AD] WORD(hellohihiii)
WORD -> fragment+ has no separator, so fragments that touch get joined. Same for single quotes, and you can mix them.
Words end at whitespace or an unquoted operator, so hello|hi is right. "a|b" is one word.
"" adds nothing: a""b is WORD(ab), and a bare "" is a WORD with an empty value.

Answer: [VR] For output redirection (>/>>), if the file does not exist, the shell creates it. So, echo "line one" > a.txt creates a.txt if a.txt does not already exist.
